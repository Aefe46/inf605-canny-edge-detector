# Canny Edge Detector

Bu proje, **Türk-Alman Üniversitesi** bünyesinde yürütülen **INF605 Görüntü İşleme** dersi kapsamında hazırlanmıştır. Kenar tespiti yöntemi olan **Canny Kenar Dedektörü**'nün (Canny, 1986) implementasyonunu ve analizini içerir: Gauss yumuşatma, gradyan hesabı, non-maximum suppression ve histerezis eşikleme.

> J. Canny, "A computational approach to edge detection," *IEEE Trans. Pattern Anal. Mach. Intell.*, vol. PAMI-8, no. 6, pp. 679–698, 1986. doi: [10.1109/TPAMI.1986.4767851](https://doi.org/10.1109/TPAMI.1986.4767851)
